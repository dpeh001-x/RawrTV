# 🎨 RAWR FIGHTS — Brand Assets

Drop the channel's logo and banner artwork here. This folder is **not**
gitignored for images, so `.png` / `.jpg` / `.svg` / `.webp` files commit
normally. (Only `*.mp4` and `output/` are ignored — see repo `.gitignore`.)

## 📁 Where things go
| Folder | What goes here |
|--------|----------------|
| `brand/logo/`    | The RAWR FIGHTS logo — ideally a **transparent PNG** (and an SVG if you have one) |
| `brand/banners/` | YouTube channel banner, thumbnail templates, TikTok header, poster art |
| `brand/` (root)  | `rawr-fights-brand.html` — the existing style/brand board |

## 🏷️ Suggested file names (keeps things tidy — not enforced)
**Logo** → `brand/logo/`
- `rawr-fights-logo.png` — primary, full-color, transparent background
- `rawr-fights-logo-white.png` — white/knockout version for dark backgrounds
- `rawr-fights-logo-mark.png` — icon/mark only (square, for avatars)
- `rawr-fights-logo.svg` — vector master, if you have one

**Banners** → `brand/banners/`
- `youtube-channel-banner.png`
- `youtube-thumbnail-template.png`
- `tiktok-header.png`
- `poster-ep1.png`, `poster-ep2.png`, `poster-ep3.png`

## 📐 Recommended specs
| Asset | Size | Notes |
|-------|------|-------|
| YouTube channel banner | **2560 × 1440 px** | Keep text/logo inside the centered **1546 × 423** "safe area" — that's all that shows on phones |
| YouTube thumbnail | **1280 × 720 px** (16:9) | Under 2 MB; big bold subject + few words |
| Channel avatar / logo mark | **800 × 800 px** square | Displays as a circle — keep the mark centered |
| TikTok / IG header | 1080 × 1080 (or per-platform) | Vertical-safe |
| Poster (short-form) | **1080 × 1920 px** (9:16) | Matches the episode aspect ratio |

Transparent PNG for the logo wherever possible so it composites over any background.
